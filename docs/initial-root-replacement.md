# Finite native initial-root replacement

This is production source architecture, not a claim of completed ForgeGradle, transformed-module,
world, geology, production-JAR or client acceptance. Shared admission and retention rules remain
owned by the [workspace documentation](../../../better-content-modpack/docs/README.md).

## Narrow authority

The optional Deep Void 1.98.1 Damned initial-spawn procedure contains four mutually exclusive native
replacement calls. The private static Mixin handler wraps exactly those four calls, with
`require = expect = allow = 4`. It neither retries until conversion nor changes native branch RNG,
position, variant, return value or call ordering. Other versions fail the optional plugin's version
check; absence skips the target. The four variants are not Damned subclasses. This is not an
unbounded-offspring or lifetime guarantee.

`CaveNativeRootBridge` is a **PUBLIC INTERNAL Mixin ABI**, necessary because the merged private
handler lives in another module. Its descriptor contains only public Minecraft, MixinExtras and JDK
types. It exposes no authority/account constructor or budget API. Without the private active initial
root frame and matching parent, level, position, reason, type and held authority, it forwards the
original operation once without granting Cave admission. Nested frames do not borrow outer authority.

All shipping authority comes from the actual live encounter, SURGE phase and existing held
cap/rate/debit reservation. Ordinary owner-null spawning gains no conversion authority. One original
charge and stable Version 1 family UUID transfer to the **actual** successful native body; there is
no second charge, descendant credit, alternate roster entry or persistent ledger. The existing
Compat event completion Boolean—not nonnull `EntityType.spawn` return—is insertion authority.
A preexisting veto is observed without uncanceling it. Candidate and expected registry type must
also have actual object identity, not merely matching textual IDs.

Preinsert validation checks provisional actual-body spatial geometry and ownership, without a path
query or an extra Cave-explicit Forge-position callback; the original engine/Forge insertion hooks
still run unchanged. Only true insertion/return/discard eligibility can reach final initialization.
After the original native procedure returns, unchanged floor/light/sky/visibility/nearest-target,
collision and border predicates must pass on the actual body. Then the existing Cave root-role
initialization sets `onGround=true`, and the same actual native `createPath`/`canReach` predicate runs,
followed by the original Cave-explicit Forge-position predicate. This deliberately does not move or
rotate the native body, retry native calls or add RNG. Initial-original + final-actual means two Cave
path queries and two explicit Cave-position checks on a successful attempt, not a third provisional
query/callback. Flags, size, live paid authority/caps and actual body validity remain required.

This is production root-role initialization, **not readonly navigation or cache equivalence**:
native pathfinding writes target/reach/timeout/stuck bookkeeping and invokes native hooks. There is
no scratch navigator, bypassed predicate or deferred admission. Failed final path/position validation
rolls back all known bodies and closes/refunds the same held charge synchronously before the caller
can return to the server tick. Cave-owned provenance/target/follow-range/ground snapshots are restored
after safe physical cleanup. Native/module execution remains separately unqualified. Failed
conversion is terminal, not another ordinary spawn attempt. Every known owned body must be removed
before refund. A broken remover freezes payment and known survivor pressure and still throws the
native failure; later bookkeeping failures are suppressed on that cause, never converted to success.

Actual member/heavy/corpse UUIDs drive existing lifecycle and Version 1 persistence. The original
family UUID stays stable. Pending root state is not serialized; no format, credits, bounds, deadline,
pacing or recovery change is introduced. Selected Damned quota canonicalization counts the actual
four variant successes once, without a second count/ledger or a policy for unrelated selections.

## Nonshipping paid catalogue

`CatalogueRootAccount` and `CatalogueRootAccess` exist only in the owning world fixture module.
Each entry gets a finite account bounded by the original 64 maximum cost, backed by the real
`DirectorRuntime.RootCharge`. It cannot reset, mint credit, retry an exhausted account or authorize
after close. It is not a public production budget or global permission switch. Both classes and
sources are excluded from runtime **and** sources archives. The subscriber checks their actual
named owning-module identity along with the existing fixture classes.

The catalogue keeps all 37 entries, exact six ecosystems, original 18 cohorts plus surface sentinel,
RNG, cadence, TPS checks and 80,000/240,000-tick deadlines. Four approved local fixture changes
(import, stronger selected/actual/paid-family assertions, paid adapter and typed result) are recorded
in `src/worldGameTest/world-initial-root-adaptations.json`. Reversing only those regions must recover
the complete retained pre-change source hash; the source control rejects any unrelated body change.

## Source controls and honest limits

Regular JVM tests inspect real compiled handler/bridge access flags and descriptors, one original
operation callsite, exact four-anchor annotation, unmoved native geometry, final ground/path/callback
ordering and count, eligibility before mutation, veto ordering, authority and
rollback. `rootContractTest` adds the finite account and reads the pinned **original** vendor archive
without loading its classes. It verifies exact archive identity, four sequential exclusive native
branches and actual generated named/SRG refmap entries. Its inputs are the owning pinned configuration
and processed AP output, never task-artifact files. `verifyFast` includes this nonshipping test set;
it remains subject to shared ForgeGradle admission, not permission to run it now.

The Minecraft-free `gradle/verify-world-fixture.py` also checks source hashes, the exact reversible
fixture changes, profile selection and synthetic leaks for both archive kinds. These do not establish
actual final archive contents, reobfuscation, transformed cross-module access or observed native
execution of all four branches. Those require their separately admitted owning gates and full
all-severity diagnostic review. Failed and partial attempts remain retained, never relabeled.
